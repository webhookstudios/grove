# Grove 1.2.1

A tidier top bar, and only Linux apps in the library.

- The All, Installed and Updates buttons sit in the middle of the top bar again, with room around them. Search is now a button at the top right that opens a search bar; you can also press Ctrl+F or just start typing.
- The library lists only Linux apps: repos whose latest release has a Debian package. Repos tagged for another system, such as Windows, Android or the web, are left out unless they are also tagged linux.

Install:

```bash
sudo apt install ./grove_1.2.1_all.deb
```
